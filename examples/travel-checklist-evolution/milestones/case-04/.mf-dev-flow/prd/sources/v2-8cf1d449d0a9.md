# 旅行清单 PRD v2

## 背景

首版筛选已经完成。旅行者希望按使用时机理解事项，并能立即看出当前筛选结果的完成情况。

## 变更需求

- 事项按“出发前”和“旅途中”两个出行阶段分组展示。
- 默认显示四项事项：“出发前”三项，“旅途中”一项。
- 用户仍可开启“仅看已完成”；筛选必须作用于每个分组中的事项。
- 页面显示当前筛选结果的进度摘要：默认显示“当前显示 4 项 · 已完成 3 项”，筛选后显示“当前显示 3 项 · 已完成 3 项”。
- 用户关闭筛选后，两个分组、四项事项和默认进度摘要必须全部恢复。

## 对既有功能的调整

首版筛选逻辑不得继续假设单一平铺列表。可见数量、完成数量和分组可见性必须从当前筛选结果统一计算，不能沿用全量统计或只隐藏视觉元素。

## 范围边界

本版不包含事项编辑、分组编辑、持久化、登录、远程同步或外部 API。

## 验收标准

1. 默认状态显示两个分组、四项事项和 4 / 3 的显示/完成摘要。
2. 开启筛选后两个分组合计只显示三项已完成事项，摘要同步为 3 / 3。
3. 关闭筛选后完整分组、事项与默认摘要恢复。
