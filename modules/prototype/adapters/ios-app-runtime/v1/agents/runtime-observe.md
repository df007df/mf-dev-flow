# iOS 原生 App 模拟器运行态附录

只在已授权的 iOS 模拟器中观察 `ios-simulator` 运行态。此适配器不具备源码发现能力；记录的范围只代表已在模拟器中观察和归档的行为，不代表源码、分支或状态空间全量。

每次界面变化前后均读取并记录当前屏幕状态：导航前的屏幕状态、触发变化的业务原因，以及变化后的屏幕状态必须可相互对应。使用稳定的元素标识（accessibility label/identifier）执行真实用户可执行的交互；不得以强制点击、坐标盲点、私有 API 或直接改写应用状态替代用户动作。

编译、安装、启动、重启模拟器、切换角色或准备数据仅可作为场景准备动作。必须在追踪中把这些准备动作与业务交互分开标记；只有用户可执行的业务操作可以用于证明业务行为。

在目标状态完整可见时保存模拟器 PNG 截图，不得以局部、遮挡或转场动画中的画面替代目标状态。为每条实际追踪写入 bundle identifier、屏幕或场景标识、element 或 action、前置条件、断言和结果，并归档该追踪；缺少任一字段时，该观察不能作为验收证据。
