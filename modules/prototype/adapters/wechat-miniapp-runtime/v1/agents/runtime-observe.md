# 微信开发者工具小程序模拟器运行态附录

只在已授权的微信开发者工具小程序模拟器中观察 `wechat-devtools-simulator` 运行态。此适配器不具备源码发现能力；记录的范围只代表已在模拟器中观察和归档的行为，不代表源码、分支或状态空间全量。

每次页面导航前后均读取并记录当前页面栈：导航前的页面栈、触发导航的业务原因，以及导航后的页面栈必须可相互对应。使用稳定 selector 执行真实用户可执行的交互；不得以强制点击、脚本点击或直接改写页面状态替代用户动作。

编译、刷新、切换角色、准备数据或展示 demo 仅可作为场景准备动作。必须在追踪中把这些准备动作与业务交互分开标记；只有用户可执行的业务操作可以用于证明业务行为。

在目标状态完整可见时保存模拟器 PNG 截图，不得以局部、遮挡或过渡中的画面替代目标状态。为每条实际追踪写入页面 route、query、selector 或 action、前置条件、断言和结果，并归档该追踪；缺少任一字段时，该观察不能作为验收证据。
