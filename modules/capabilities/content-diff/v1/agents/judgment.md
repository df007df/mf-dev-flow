# 内容比对判定简报（content-diff v1）

- `content hash` 给字节指纹（留版本痕迹、本地对比）；`content compare` 默认归一化（CRLF、行尾与纯空白行差异视为未变），`--strict` 按字节。
- 判定"变了没有、变了哪里"以 compare 的分块行级差异为准；引用差异时带 op 与两侧行号，不得凭记忆描述。
- 归一化判"未变"但 strict 有差时，如实说明只差空白/换行，不改写为实质变更；反之实质变更不得用归一化口径淡化。
- 冻结快照（如 PRD source）与重取候选比较后，受影响结论条目走对应流程复评（如 prd check --against）。
