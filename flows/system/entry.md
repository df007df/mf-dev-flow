# 外部系统事实

触发：提供外部代码、DB、配置、接口或数据，核对系统能力或回答系统卡片问题。输入为明确外部系统定位与已授权只读范围；输出是系统卡片、API 使用、问题、约定与历史。

先 `system status`，用 `system query --limit 10 --json` 定位并按卡分段读取，执行前读 [系统协议](protocol.md)。若只补齐一条已有卡片的公开测试/线上 origin，且已有脱敏可复核证据，可用 `system profile-address` 直接登记；其他系统事实、配置或接口变化仍创建 system 运行。指定运行续做用 `run context --id <ID>`；选择目标卡片与当前问题，按专用 system 命令登记结论，不展开所有卡片。

外部代码、配置只读，DB 仅元数据和 SELECT；凭证值不进入记录或输出。事实、推断、候选 API 和未解决问题明确区分。外部系统不要求启动和测试通过，也不冒充本地交付项目。

回答只处理用户已回答部分，保留其余待确认项与历史。完成系统卡片核验后，若用户要求更新规划，交接 [规划入口](../planning/entry.md)；不会自动开始开发。
