# 项目与环境登记

触发：初始化项目管理、登记可开发代码根、核验本地运行环境。输入为用户指定的项目、来源与写入边界；输出为 project.json、项目卡片和实测检查。

先 `project status`；尚未登记且用户授权初始化时按 [项目协议](protocol.md) 执行 init。已有项目先核对目标卡片，明确 target / reference 角色。不要把首次只读检查变成自动初始化。

本地可开发项目首次登记必须实际启动并通过 test 和 test:e2e；缺失命令或失败明确记录 failed。配置和数据边界只读核对，凭证不入报告。外部参考系统交给 [系统流程](../system/entry.md)。

环境、目录、E2E 与截图来源核验后形成可用卡片；用户要求规划或交付时分别交接相应流程，维护技能时不运行这些项目检查。
