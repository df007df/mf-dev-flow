# 上下文与看板

触发：查看任务、运行、证据、状态或看板。输入为明确对象或会话；输出为只读摘要与下一步定位。

先 `flow route --session <ID>`；指定运行用 `run context --id <ID>`。先读 brief，按 `--detail <分区>`、对象筛选和 cursor 补证，不读全量历史。只有需要查看/重建当前运行指针才调用 current。

查看看板时读 [看板说明](dashboard.md)；核验状态和结束规则时读 [记录协议](records.md)。原型界面只经公共 CLI 分页读取，完整报告按需加载，按钮先预览提示词再复制。

不把只读请求变成建库、初始化、扫描或迁移。发现阻塞就指出对象与对应流程；继续工作需遵守已有范围与授权。compact 是显式重建派生摘要，不改变原始历史。
